# 偶数位宽整数测试

在仓库根目录构建并测试最新版编译器：

```sh
cmake -S ArkLink -B ArkLink/build
cmake --build ArkLink/build
cd Re.KrtC
zig build
cd ..
python3 -m unittest discover -s Test/IntegerWidths -p 'test_*.py'
bash Test/SyntaxAudit/run.sh
```

可设置 `KRTC` 为编译器的绝对路径。整数测试在临时目录生成、编译和执行程序，结束后自动清理。

- 遍历全部 64 个偶数位宽，分别验证有符号和无符号类型。
- 检查极值、回绕、精确十进制/十六进制/二进制字面量、算术、比较、位运算及符号扩展。
- 用固定随机种子对 64、66、96、126、128 位运算与 Python 整数结果比较。
- 检查 0、63、64、65、127、128 等移位数，以及跨寄存器传参、返回值、前向调用和类方法重载。
- 检查全局常量表达式、类字段、数组元素、数组参数、三元表达式、自增和自减。
- 拒绝超过 uint128 上限的字面量。
- 检查一元运算优先级、前后置自增自减、超大移位数、IR 字面量精度和旧后端诊断。
- 检查寄存器打包后相邻变量独立读写、所有非整 64 位片段、混合参数、循环和递归。
- 用 180 个两位整数检查寄存器空间不足时的栈回退，并检查长变量名与作用域遮蔽。
- 使用 `objdump` 检查四个变量实际共用一个物理寄存器；未安装该工具时仅跳过这项机器码检查。
