2026-09-12 本机结果，AMD Ryzen 9 8945HX，Linux x86-64，GCC 16.2.1：

| 实现 | Fib35，10 次均值 | Fib40，10 次均值 |
|---|---:|---:|
| 手写 x86-64 ASM | 27.408742 ms | 305.026602 ms |
| C，`-O2 -fno-optimize-sibling-calls` | 27.333942 ms | 304.552275 ms |
| C，普通 `-O2` | 16.848287 ms | 189.094661 ms |

两种源码使用相同的 `n <= 1 ? n : fib(n-1) + fib(n-2)` 递推，无缓存。
反汇编确认 ASM 和限制优化的 C 每层保留两个递归调用点；本机 GCC 普通 `-O2` 将其中一个分支变为循环，所以单独列出。

固定逻辑 CPU 0，串行运行，每轮轮换实现的先后顺序。用 `CLOCK_MONOTONIC_RAW` 计时，仅包含一次 `fib(n)`，排除编译、进程启动和输出。输入来自命令行，C 函数位于独立编译单元，禁用内联和 LTO。所有样本均保留，不做预热或剔除。

运行前验证 n=0/1/2/10；每个计时样本验证 Fib35=9227465、Fib40=102334155。
`../NativeFibResults.json` 保存全部 60 个样本、标准差、环境、编译参数、源码散列及反汇编。这是本次机器状态下的测量值，回归测试不硬编码耗时阈值。
