# 指针类型与空值

类型绑定和泛型实例化在类型 AST 中保留每一层指针的空值标记。原生和 VM 目标共用这些绑定检查，并执行类型模式生成的地址非零测试；SSA 和 VM 不另行追踪每一层的空值状态。直接调用和函数指针调用使用相同的参数匹配规则；`ref` 要求完整类型一致。

## 类型后缀

类型后缀按源码顺序应用，`?` 修饰它前面的完整类型。

| 类型 | 含义 |
| --- | --- |
| `int32*` | 非空的整数指针 |
| `int32*?` | 可为空的整数指针 |
| `int32*?*` | 非空指针，指向一个可为空的整数指针槽位 |
| `int32**?` | 可为空的指针，指向一个非空的整数指针槽位 |
| `int32*?[]` | 数组元素为可空整数指针 |
| `int32*[]?` | 可空数组，元素为非空整数指针 |
| `int32*?[]?` | 可空数组，元素也为可空整数指针 |

裸数据指针和标量函数指针接受 `null` 时需要外层空值标记。局部非空指针必须初始化，`default(int32*)` 等非空指针默认值会被拒绝。裸指针转换、赋值和参数传递不能删除已有的外层或所指槽位的空值标记。

类、接口、字符串和动态数组保持已有的可空引用规则；普通 `[]` 也接受 `null`，不能据此认为数组引用非空。`[]?` 的外层标记保留在类型身份和 ABI 中，但普通数组赋值不以它建立非空保证。结构体和数组的零初始化也不是对其每个指针字段的运行时非空证明。

## 在成功分支中使用指针

`is` 模式验证地址非零，并在成功分支绑定具有相同内部类型的非空变量。原变量的声明类型保持不变。

```kairote
int32 Read(int32*? pointer) {
    unsafe(using krt.mem;) {
        if (pointer is int32* live) { return *live; }
        return 0;
    }
}
```

可空指针不能直接解引用、索引、参与地址算术或自增自减。类型模式只能去掉外层空值标记，不能改变所指类型、内部空值层或回调签名。普通 `pointer != null` 比较不改变变量的静态类型。

泛型 `T?` 同样保留完整形状，包含函数指针。函数类型语法中的 `fn()->int32?` 将 `?` 应用到返回类型，不能用它声明可空回调。已推断为回调的泛型 `T` 可以使用 `T?`，再通过 `is T live` 调用。

## 空值回退与条件访问

`pointer ?? fallback`、`callback ?? fallback` 只在左侧地址为空时求值右侧，左侧只求值一次。两侧必须保持完整内部类型和回调签名；结果的最外层空值标记由右侧决定，不能借此删除所指槽位的空值标记。动态数组与字符串也可使用 `??`，数组元素类型仍需一致。

`pointer?[index]` 在接收者为空时跳过索引求值，并返回元素类型的零值；结果元素是裸指针或回调时保留可空标记。类、接口、数组与字符串支持对应的 `?.` 成员访问。整个未分组后缀链共享该空值检查，括号结束条件链。条件访问结果是值，不能直接取地址或用作 writable ref；普通方法的 ref 实参仍按已有规则绑定并仅在调用执行时求值。结构体和固定数组结果使用独立的完整值副本。

动态选择的回调只保留各分支共同的形参名，包含返回值和参数中的嵌套回调；没有共同名称时使用位置参数。完整规则见 [SelfHost README](../../SelfHost/README.md#空值运算与循环变量)，测试见 `test_nullable_operators.py` 和 `test_nested_callback_contracts.py`。

## 地址算术与布局

数据指针加减整数、自增自减和复合赋值按完整元素大小移动；偏移当前限于最多 64 位的非布尔整数，不支持更宽整数偏移。同形指针相减得到有符号 `int64` 元素距离。前置声明和递归指针字段在布局完成后使用规范元素布局；指针数组的元素自身仍占一个指针槽位。

指针之间相加、整数减指针、浮点或布尔偏移、乘除、位运算和不同元素类型的指针相减会被拒绝。`void*` 没有可用元素大小，不能解引用、索引或移动；`void**` 的元素是指针，具有明确大小。标量函数指针只允许相等和不等比较，不能当作数据指针参与算术。

数组和字符串的显式裸指针地址视图仍可用于系统调用。此类转换检查外层和所指槽位的空值信息，不能把浮点数转换为指针。这些地址操作不提供边界检查或内存生命周期检查。

数组到数组的显式转换检查完整元素形状，可以增加元素的外层或所指槽位的空值标记，不能删除已有标记。回调元素的参数、返回类型和 `ref` 属性必须一致。数组引用自身仍使用前述可空规则；从 `[]?` 转换为普通 `[]` 不建立非空保证。
