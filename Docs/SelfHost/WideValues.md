# 宽整数的值存储

65–128 位整数保持声明的精度和符号，使用 16 字节载荷。局部变量、按值参数、类字段、结构体字段、数组元素、捕获单元和生成器状态保存自己的值副本。赋值与返回不会保留临时计算结果的地址。

读取可变位置时立即复制值。例如 `value + value++` 的左操作数在右操作数修改变量之前求值。普通数值转换仍执行精度掩码和符号扩展；转换后再复制到目标存储。

Native 和 VM 为每条产生宽整数结果的指令分配固定的函数帧临时区。循环重复使用该指令的临时区，递归调用拥有独立的帧。持久值在写入时复制，因此复用临时区不会改变此前保存的值。异常展开直接丢弃函数帧。

宽整数返回值使用调用者分配的 16 字节缓冲区，沿用结构体的返回机制。直接宽整数参数、返回值、`ref` 参数及包含这些边界的回调使用带 `KRTWIDE3` 标记的原生 ABI3 契约。包含宽字段的普通结构体继续使用已有的结构体 ABI2。具体版本检查见 [模块 ABI](ModuleAbi.md)。

VM 版本 6 使用相同的按值约定和固定临时区；版本 1–5 保留各自已有的解释规则。运行时类型描述符加载到独立的对齐存储中，字符串字节数不会影响异常类型标记。
